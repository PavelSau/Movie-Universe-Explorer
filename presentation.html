1 — The Problem

Cinema is a connected universe.
But you browse it as isolated pages.

Dead Ends

IMDb shows a movie page. You click an actor. Another page. No connections visible.

No Big Picture

How did Brad Pitt's career evolve? Which genres dominate each decade? No visual answer.

Hidden Patterns

Directors who recast the same actors. Genre waves over time. Invisible in current tools.

The solution: Turn the movie industry into an interactive, explorable graph of connections, timelines, and heatmaps.

5 — When Claude Fought Back

Problems Claude created and couldn't easily fix

overflow-hidden
Search dropdown invisible behind hero section
Claude kept adding overflow-hidden to layout containers. Search results were clipped. I had to explicitly say "I hate overflow-hidden" and add it to the Do NOT list in CLAUDE.md. Took 3 rounds to fully fix.
Hardcoded colors
Kept using bg-gray-*, text-white, bg-black
Even after setting up CSS variables and shadcn tokens, Claude repeatedly hardcoded colors. Used raw <input> instead of shadcn Input. Had to get angry and add strict rules to CLAUDE.md. Only then it stopped.
D3 graph
Expand/collapse cycle completely broken
First D3 graph implementation: no drag, no dedup, broken zoom, tooltip appeared randomly. Needed a full rewrite. Then expand-collapse toggled wrong state — double-toggle bug. Took 4 fix commits.
Heatmap API
Infinite API calls crashing the backend
First heatmap implementation fired hundreds of TMDb API calls (one per genre+decade combo). Had to say "Heatmap is full shit, it triggers infinite calls." Rewritten to use just 5 batched calls.
5 — Lessons Learned

What actually worked

01
CLAUDE.md is the most important file
Every time Claude broke a rule, I added it to CLAUDE.md. By commit 10, it stopped making those mistakes. The rules file grew WITH the project.
02
Multi-agent = massive parallelism
2 devs built Timeline+Heatmap simultaneously. 3 devs built 3 features in parallel. 5 QA agents wrote 345 tests in one pass. Architect reviewed each batch.
03
You must review like a tech lead
Claude writes code fast but makes subtle UI/UX mistakes. I caught every overflow-hidden, every hardcoded color, every broken interaction. The human eye is still essential.
04
Worktrees prevent agent collisions
Each parallel agent got its own git worktree. No merge conflicts, no file stomping. Architect merged the results after reviewing.
